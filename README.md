# Óleo pela Placa

Aplicativo Android gratuito para consultar e cadastrar a especificação de óleo associada à placa de um veículo.

O APK de teste é compilado automaticamente pelo GitHub Actions a cada atualização do projeto.

> Atenção: viscosidade, norma e capacidade devem ser confirmadas conforme ano, motor e manual do fabricante. A consulta automática de qualquer placa requer uma fonte/API autorizada.
